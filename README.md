# 교실 도구 허브 사용과 개발

## 로컬에서 실행하기

Windows에서 `start.cmd`를 더블클릭하고 브라우저로 `http://127.0.0.1:4173`에 접속합니다. 실행 창을 열어두고 사용하며, 종료할 때 창에서 Ctrl+C를 누릅니다. 이 실행 주소는 현재 PC에서만 접근할 수 있습니다.

Node.js 24.21.0 이상이 설치되어 있으면 다음 명령으로도 실행할 수 있습니다. 로컬 사용에는 패키지 설치나 빌드가 필요하지 않습니다. `start.cmd`는 PATH에 설치된 Node.js를 사용합니다. 공개 배포본은 아래의 별도 빌드 명령으로 만듭니다.

```powershell
cd classroom-hub
node scripts/serve.mjs
```

4173 포트가 다른 프로그램에서 사용 중이라면 다음처럼 바꿉니다.

```powershell
$env:PORT = '4174'
node scripts/serve.mjs
```

HTML 파일을 직접 더블클릭하면 브라우저의 모듈 보안 제한으로 작동하지 않을 수 있으므로 로컬 서버를 사용합니다. 이 서버는 개발용이며 인터넷 배포 서버로 사용하지 않습니다.

## 수업에서 사용하기

1. 도구함의 교실 타이머 카드를 선택합니다.
2. 1·3·5·10분을 선택하거나 분·초를 입력합니다. 1초부터 99분 59초까지 사용할 수 있습니다.
3. 시작하기를 누르고 필요하면 전체화면으로 확대합니다.
4. 일시정지·계속하기·초기화를 사용합니다. 종료 시 화면 안내와 선택된 소리가 나옵니다.

소리를 끌 수 있고, 전체화면을 사용할 수 없으면 화면 내 확대가 적용됩니다. 도구함 복귀 시 일시정지되며 돌아와 계속할 수 있습니다. 새로고침·탭 종료 시 설정은 초기화됩니다. 모바일 잠금·절전·숨겨진 탭에서는 알림이 늦어질 수 있으므로 수업 중에는 화면을 켜둡니다. 각 기기는 독립적으로 작동합니다.

## PDF 글자 수·교정 후보 검사

도구함에서 **PDF 검사**를 선택하거나 `http://127.0.0.1:4173/#/pdf`로 접속합니다. PDF 한 개를 선택하거나 끌어놓으면 전체·쪽별 글자 수와 흔한 한글 오타·띄어쓰기 교정 후보를 표시합니다. 결과는 **엑셀 다운로드**로 `.xlsx` 파일을 받습니다. 검사 요약과 교정 후보 두 시트가 포함됩니다.

텍스트가 없는 쪽은 한글·영문 OCR로 읽습니다. 글과 사진이 섞인 쪽은 **모든 쪽을 OCR로 읽기**를 선택하세요. 흐린 사진·표·여러 단·손글씨에서는 누락이나 오인식이 생기므로 쪽별 추출 내용과 원문을 비교해야 합니다. 교정 후보는 등록된 규칙만 검사하며 정밀 문맥·문법 검사가 아닙니다. 후보가 없다고 오류가 없는 것은 아닙니다.

공백 포함 글자 수는 줄바꿈을 제외하고 문장부호를 포함합니다. 공백 제외는 공백·탭·줄바꿈을 제외합니다. 한글 조합 문자와 이모지는 보이는 문자 단위로 세며 머리말·꼬리말도 포함합니다. OCR 결과에 따라 수치가 달라질 수 있습니다. 제한은 **25MB, 100쪽, 추출 텍스트 200만 코드 단위, 교정 후보 1만 개, 처리 10분**입니다. 암호가 필요한 PDF는 지원하지 않습니다. 오류 시 불완전한 결과를 내보내지 않습니다.

PDF와 결과는 현재 브라우저 메모리에서만 처리합니다. 업로드·분석 API·브라우저 영구 저장을 사용하지 않으며 지우기·도구함 이동·새로고침으로 상태를 폐기합니다. OCR 엔진과 언어 모델도 앱의 정적 파일에 포함되어 CDN 접속이 없습니다. 메모리의 보안 삭제를 보장하는 기능은 아닙니다. 선택한 파일명과 전체 원문은 엑셀에 넣지 않습니다. **주변 문맥 포함**은 기본으로 꺼져 있으며, 켜면 원문의 일부와 개인정보가 내려받은 파일에 포함될 수 있습니다. 사용자가 저장한 엑셀 파일은 자동 암호화되지 않습니다.

처음 OCR을 실행하면 포함된 엔진·모델 약 20MB를 읽으므로 일반 텍스트 PDF보다 느립니다. 스마트폰에서는 큰 스캔 문서를 여러 작은 PDF로 나누면 부담을 줄일 수 있습니다. 인터넷 주소로 공개하더라도 문서는 브라우저 안에서 처리되지만 정적 호스팅의 일반 접속 기록은 별도로 확인해야 합니다.

## 다항식 숲 탐험

허브의 **다항식 숲 탐험** 카드 또는 `http://127.0.0.1:4173/#/polynomial`에서 실행합니다. 다람쥐·거북이의 이동·점프 능력은 같습니다. 고1 공통수학1 다항식의 연산, 항등식·나머지정리·인수정리, 인수분해를 세 길로 나누고 각 길에 직접 작성한 4지선다 6문제(총 18문제)와 해설을 제공합니다. 문제·정답을 수정하려면 `dist/polynomial-data.mjs`를 편집합니다.

PC에서는 게임 화면을 선택하고 방향키 또는 A/D로 이동, 스페이스·위쪽 방향키·W로 점프, P로 일시정지합니다. 모바일에서는 좌우·점프 버튼을 사용합니다. 물음표에서 문제를 풀 때는 게임이 멈춥니다. 정답 +100점, 도토리 +10점, 나무 충돌 −20점이며 0점 미만으로 내려가지 않습니다. 충돌 시 직전 문제 뒤로 돌아가고 이미 푼 문제나 모은 도토리로 중복 점수를 받지 않습니다. 자동 이동·퀴즈 집중 모드도 제공합니다.

뱃지는 세 길의 완주, 한 길의 6문제 전부 정답, 직접 이동 모드에서 무충돌 완주, 두 캐릭터로 각각 완주로 얻는 총 6종입니다. 모든 길을 처음부터 선택할 수 있습니다. 완료 화면에 정답 수·점수와 전체 문제의 내 답·정답·해설을 표시합니다. 최고점·뱃지·완주 캐릭터만 현재 브라우저에 저장하며 이름·학교·학번·개별 응답은 영구 저장하지 않습니다. 자동 이동 모드에서도 학습 뱃지는 얻지만 점프 뱃지는 얻지 않습니다.

저장 차단 시 화면에 안내하고 메모리에서 계속 사용합니다. 새로고침·선택 화면 이동은 진행 중 탐험을 종료하며 완주 기록만 유지합니다. 다른 탭·창으로 이동하면 자동 일시정지하고 복귀 후 계속하기를 눌러야 합니다. ‘이 게임 기록 지우기’는 두 번 확인해서 이 게임의 기록만 삭제합니다. 저장 기록은 기기 간 동기화되지 않으며 브라우저 설정 변경으로 사라질 수 있습니다. 점수는 개인 복습용이고 성적 평가·부정행위 방지 기능은 없습니다.

신규 외부 라이브러리나 온라인 이미지·글꼴·분석 서비스 없이 캔버스 그림과 기존 허브 디자인을 사용합니다. 허브 연결은 기존 로컬 프로젝트 안에서 완료했으며 인터넷 배포는 포함하지 않습니다.

## 새 도구 등록

`dist/tools.mjs`에 고유 ID·이름·설명·경로를 추가하고 `dist/app.mjs`의 `routes`에 해당 화면의 렌더 함수를 등록합니다. 등록된 내부 경로만 카드로 표시되며, 화면 함수를 등록하지 않은 카드나 중복 ID·경로는 제외됩니다.

```javascript
// tools.mjs의 tools 배열에 추가하는 합성 예시
{ id: 'example-tool', title: '예시 도구', description: '새 도구의 설명',
  route: '#/example', category: '수업 도구' }

// app.mjs의 routes 목록에, 해당 화면 함수를 import한 후 추가
['#/example', () => renderExample(main)]
```

화면은 떠날 때 타이머·작업·이벤트를 정리하는 함수를 반환할 수 있습니다. `hub-view.mjs`에서 도구별 장식을 구분합니다. 새 도구가 학생 정보·로그인·외부 API를 사용한다면 해당 기능의 보안·권한 설계를 별도로 진행합니다.

## 테스트

```powershell
node --test tests/*.test.mjs
```

브라우저 점검은 기존 Playwright와 Chrome이 설치된 환경에서만 실행합니다. 앱 구동에는 이 도구들이 필요하지 않으며 신규 패키지를 자동 설치하지 않습니다. 로컬 서버를 실행한 상태에서 기존 Playwright의 `index.mjs` 절대 경로를 전달합니다.

```powershell
node tests/browser-check.mjs '<기존 Playwright의 index.mjs 절대 경로>'
```

Edge를 검사하려면 `$env:BROWSER_CHANNEL = 'msedge'`를 먼저 설정합니다. 허브·타이머 브라우저 점검은 기본 포트 4173 또는 환경 변수 PORT를 사용합니다. 공개 미리보기를 검사할 때는 `$env:PREVIEW_STATIC = '1'`을 지정합니다. 화면 이미지는 `qa` 폴더에 생성되며 버전 관리에서 제외됩니다. 자세한 결과와 미검증 환경은 `AUDIT.md`에 기록합니다.

PDF 통합 검사는 `node tests/pdf-browser-check.mjs '<Playwright index.mjs 경로>' '<선택: openpyxl·pypdf 설치된 Python 경로>'`로 실행합니다. 개인 정보가 없는 합성 PDF를 메모리에서 생성하며 스캔 OCR·다운로드·취소·암호·자원 제한·외부 요청과 저장소 사용을 검사합니다. Edge 자체 다운로드 패널의 `edge:` 요청은 외부 통신과 구분합니다. 앱 실행에 Python·Playwright는 필요하지 않습니다.

## 인터넷 주소로 배포하기

배포 대상은 **`build/static` 폴더**입니다. `dist`는 타이머·PDF·다항식 게임의 공개 소스입니다. GitHub 소스 공개와 실제 인터넷 호스팅은 별도 작업입니다.

```powershell
node scripts/build-static.mjs
node scripts/preview-static.mjs
```

첫 명령은 설치·다운로드 없이 고정된 vendor 해시를 검사하고 공개 파일을 생성합니다. 알 수 없는 입력 파일·심볼릭 링크·수정된 기존 빌드가 있으면 자동 삭제하지 않고 실패합니다. 새 도구를 추가할 때는 `scripts/build-static.mjs`의 공개 파일 허용 목록도 검토합니다. 두 번째 명령은 생성된 공개 파일만 loopback에서 제공하며 일기 데이터 폴더나 잠금 파일을 만들지 않습니다. npm 사용 시 `npm run build`, `npm run preview`도 같습니다.

빌드는 `build/.build.lock`으로 중복 실행을 거부하며 기존 공개본을 임시 보관한 뒤 새 공개본으로 교체합니다. 강제 종료 뒤 잠금이나 `.previous-*` 폴더가 남았다면 모든 빌드가 종료됐음을 확인하고 기존 파일과 릴리스 기록을 보존한 뒤 복구하세요. 남은 잠금을 자동으로 제거하거나 알 수 없는 파일을 덮어쓰지 않습니다.

`build/security-headers.json`에는 호스팅에 적용할 기본 헤더와 `/ocr-worker.js` 전체 대체 헤더, JavaScript MIME 요구사항이 들어 있습니다. **호스팅이 이 JSON을 자동 적용한다고 가정하지 않습니다.** 선택한 호스팅의 실제 헤더 설정으로 옮기고 HTTPS 응답을 검사해야 합니다. OCR 경로에는 기본 CSP와 별도 CSP를 중복 추가하지 말고 해당 경로용 CSP로 교체하세요. 기본 정책에 남은 Wasm 차단이 함께 적용되면 OCR이 작동하지 않습니다. 헤더 설정을 지원하지 않거나 실제 검증에 실패하면 배포를 보류합니다.

공개 화면·OCR worker 모두 `connect-src 'none'`입니다. 일반 화면은 `script-src 'self'`, `/ocr-worker.js`만 `script-src 'self' 'wasm-unsafe-eval'`입니다. 이는 OCR WebAssembly 컴파일용이며 일반 JavaScript eval은 허용하지 않습니다. `frame-ancestors 'none'`과 `X-Frame-Options: DENY`는 응답 헤더로 적용합니다. `.mjs`·`.js`는 JavaScript MIME으로 제공해야 합니다. 학교망·접속 로그 보관·실제 기기를 별도로 검증합니다.

`build/static/BUILD-MANIFEST.json`은 파일별 SHA-256과 릴리스 ID를 기록합니다. 같은 배포본은 `build/releases/<릴리스 ID>/`에 보관되어 롤백에 사용할 수 있습니다. 빌드 폴더는 Git에서 제외하므로 운영자가 별도 안전한 저장소에 보관해야 합니다. 이 기록은 소스 Git 이력을 대체하지 않습니다. 배포 전 소스 기준 커밋도 필요하며 이 작업은 Git 쓰기 권한을 변경하지 않습니다.

의존성 버전·라이선스는 `THIRD_PARTY.md`, 로컬 고정 해시는 `scripts/vendor-checksums.json`에 있습니다. `node scripts/verify-vendor.mjs`는 파일 변조만 검사합니다. 공개 전 보안 검토 결과와 남은 검증 범위는 `SECURITY-AUDIT.md`를 확인하세요.
